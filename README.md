# DevOps Learning Project

## 📋 Описание

Учебный проект, демонстрирующий полный цикл DevOps:
- **Инфраструктура как код** (Terraform) — управление Docker-контейнерами.
- **Конфигурация** (Ansible) — настройка VM (Docker, Buildx, runner).
- **Контейнеризация** (Docker) — Python-приложение + PostgreSQL.
- **CI/CD** (GitHub Actions) — сборка образа, пуш в GHCR, деплой на self-hosted runner.
- **Мониторинг** (Prometheus + Grafana) — сбор метрик и дашборды.
